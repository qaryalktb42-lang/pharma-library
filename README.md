# PHARMA LIBRARY — Android

تطبيق Android أصلي باستخدام Kotlin وJetpack Compose، بواجهة عربية RTL. المشروع يتطور على مراحل من نسخة تأسيسية إلى مكتبة صيدلانية قابلة للربط بـSupabase.

## المرحلة الحالية: Local-first

تم تنفيذ نسخة محلية قابلة للاستخدام دون حساب أو اتصال بقاعدة بيانات:

- كتالوج السنوات الدراسية والفصول والمواد والدفعات.
- تصفح المحاضرات وأقسام المحتوى.
- بحث عربي مبسط مع توحيد الألف والهمزات والتشكيل.
- المفضلة للمحاضرات.
- صفحة التنزيلات وإدارة حالة الملفات المحفوظة محلياً.
- لوحة إدارة محلية توضح الإحصاءات وبنية الصلاحيات القادمة.
- فصل نماذج البيانات والمستودع المحلي عن واجهة Compose في `LocalLibrary.kt`.
- تنقل فعلي بين جميع المستويات الأكاديمية، بدل صفحات Placeholder.
- إضافة مخطط Supabase أولي في `supabase/migrations/0001_pharma_library.sql` يتضمن الجداول والعلاقات وRLS وBucket خاص.
- إضافة عميل Supabase Kotlin في `SupabaseClient.kt` مع قراءة الإعدادات من `local.properties` أو GitHub Secrets. أسماء أسرار Actions المطلوبة هي `SUPABASE_URL` و`SUPABASE_PUBLISHABLE_KEY`.

البيانات الحالية تعليمية محلية وليست محتوى سحابياً نهائياً. لا يتم اختلاق ملفات أو حسابات أو صلاحيات حقيقية قبل ربط Supabase.

مخطط Supabase موجود في المستودع للتحضير، لكنه لم يُطبّق على مشروع Supabase عن بُعد بعد. ملفات Storage خاصة، وسيحتاج عرضها للطلاب إلى signed URLs من طبقة موثوقة عند تنفيذ الربط.

تم اختبار Project URL وPublishable key فعلياً؛ الاتصال يستجيب، لكن جدول `study_years` غير موجود حتى الآن. تعذر على اتصال GitHub الحالي إنشاء Secrets تلقائياً بسبب صلاحية Actions، لذلك يجب إضافتهما يدوياً من إعدادات المستودع قبل الاعتماد على APK السحابي. يجب تشغيل ملف migration في Supabase SQL Editor قبل تحميل البيانات.

## ما سيأتي عند ربط Supabase

- الجداول والعلاقات وRLS.
- مصادقة المالك والمشرفين.
- صلاحيات المشرفين حسب المواد.
- Supabase Storage لرفع ملفات PDF والصور والصوت والفيديو.
- معاينة الملفات والتنزيل الحقيقي والعمل دون اتصال.
- إدارة المحتوى والإعلانات وسجل العمليات.

## البناء

```bash
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleDebug
```

الناتج: `app/build/outputs/apk/debug/app-debug.apk`

## GitHub Actions

يشغل Workflow باسم **Build PHARMA LIBRARY APK** عند الدفع إلى `main` أو يدوياً، ويستخدم JDK 17 وGradle Wrapper 8.11.1 وAndroid SDK 35، ثم يتحقق من APK ويرفعه كـArtifact.

## الأمان

لا توجد مفاتيح Supabase أو كلمات مرور أو `service_role key` في التطبيق. عند الربط القادم سيُستخدم مفتاح العميل العام فقط، وستُطبق الصلاحيات في RLS والخادم وليس في الواجهة فقط.
